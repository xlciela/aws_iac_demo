GitHub/GitLab → CodePipeline → CodeBuild → ECR → ECS
     ↓              ↓            ↓        ↓     ↓
   Webhook    Service Role  Service Role  Registry  Cluster/Service
-------------
1. Source Code (GitHub) 
   ↓
2. CodeBuild (Build Process)
   - Build Docker image
   - Run tests  
   - Push image to ECR
   ↓
3. ECR (Container Registry)
   - Stores Docker images
   ↓
4. ECS Service (Deployment Target)
   - Pulls new image from ECR
   - Performs rolling update
   - Manages container lifecycle
   
-------------------------
step1. preparation: IAM work
- ~create IAM user~
- Create IAM Role for CodePipeline
- Create IAM Role for CodeBuild with permissions to access ECR and ECS
- Create ECS Task Execution Role with permissions to pull images from ECR
- Create ECS Task Role for application-specific permissions

step2. preparation: ECR repository
- Create an ECR repository to store Docker images
- Configure repository policies for access control
- Enable image scanning for security vulnerabilities
- Set up lifecycle policies to manage image retention
- Configure cross-region replication if needed

step3. preparation: ECS cluster and service
- Create an ECS cluster
- Create a task definition with container specifications
   - Define container image (from ECR or Docker Hub)
   - Set CPU and memory requirements
   - Configure port mappings
   - Set environment variables
- Create an ECS service
   - Link to the task definition
   - Set desired task count
   - Configure load balancer (ALB/NLB) if needed
   - Set up service discovery if required
- Create ECR repository to store Docker images
   ```
   aws ecr create-repository --repository-name ci-cd-show
   ```
- Configure IAM roles:
   - ECS Task Execution Role (for pulling images from ECR)
   - ECS Task Role (for application permissions)
step4. work on CodeCommit
- Create a CodeCommit repository
- Install git locally
- Clone the repository locally
   - edit locally, then use git add -A, git commit -m comment:string, git push

step5. necessary files for ECS deployment
- Dockerfile (defines container image)
   ```
   FROM node:16-alpine
   WORKDIR /app
   COPY package*.json ./
   RUN npm install
   COPY . .
   EXPOSE 3000
   CMD ["npm", "start"]
   ```
- task-definition.json (ECS task definition)
   ```
   {
     "family": "ci-cd-show",
     "networkMode": "awsvpc",
     "requiresCompatibilities": ["FARGATE"],
     "cpu": "256",
     "memory": "512",
     "executionRoleArn": "arn:aws:iam::account:role/ecsTaskExecutionRole",
     "containerDefinitions": [
       {
         "name": "ci-cd-show",
         "image": "account.dkr.ecr.region.amazonaws.com/ci-cd-show:latest",
         "portMappings": [
           {
             "containerPort": 3000,
             "protocol": "tcp"
           }
         ],
         "essential": true,
         "logConfiguration": {
           "logDriver": "awslogs",
           "options": {
             "awslogs-group": "/ecs/ci-cd-show",
             "awslogs-region": "us-east-1",
             "awslogs-stream-prefix": "ecs"
           }
         }
       }
     ]
   }
   ```

step6. create CodeBuild project
   - Create a new CodeBuild project
   - Configure source to point to CodeCommit repository
   - Set environment to use a managed image with Docker support
   - Enable privileged mode for Docker builds
   - Configure buildspec.yml (build instructions)
   ```
   version: 0.2
   phases:
     pre_build:
       commands:
         - echo Logging in to Amazon ECR...
         - aws ecr get-login-password --region $AWS_DEFAULT_REGION | docker login --username AWS --password-stdin $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com
     build:
       commands:
         - echo Build started on `date`
         - echo Building the Docker image...
         - docker build -t $IMAGE_REPO_NAME:$IMAGE_TAG .
         - docker tag $IMAGE_REPO_NAME:$IMAGE_TAG $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/$IMAGE_REPO_NAME:$IMAGE_TAG
     post_build:
       commands:
         - echo Build completed on `date`
         - echo Pushing the Docker image...
         - docker push $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/$IMAGE_REPO_NAME:$IMAGE_TAG
         - echo Writing image definitions file...
         - printf '[{"name":"ci-cd-show","imageUri":"%s"}]' $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/$IMAGE_REPO_NAME:$IMAGE_TAG > imagedefinitions.json
   artifacts:
       files:
          - imagedefinitions.json
   ```

step7. configure ECS deployment
   - No need for CodeDeploy application for ECS
   - ECS service will automatically handle rolling deployments
   - Configure ECS service update strategy:
     - Rolling update (default)
     - Blue/Green deployment (using CodeDeploy for ECS if needed)
   - Set deployment configuration:
     - Minimum healthy percent: 50%
     - Maximum percent: 200%

step8. create CodePipeline
   - Create a new CodePipeline
   - Set source stage to : CodeCommit repository | GitHub | AmazonECR |...
      - Set check method: Amazon CloudWatch Events | AWS CodePipeline
   - *Add build stage with the CodeBuild project
   - Add deploy stage with ECS deployment:
      - Deployment Approach: ECS (deploy to ECS service)
      - Select ECS cluster and service name
      - Input artifact: imagedefinitions.json from CodeBuild
   - Review and create the pipeline

step9. test the pipeline
   - Make changes to the CodeCommit repository
   - Commit and push changes
   - Monitor the pipeline execution in CodePipeline console
   - Verify deployment in ECS console:
     - Check service status
     - Monitor task health
     - View container logs in CloudWatch
   - Test application through load balancer endpoint
