# what is Nginx
is a web server and reverse proxy server. 
is widely used to serve static content, handle concurrent connections, 
and act as a load balancer for web applications.
### features
* 高性能: 采用事件驱动架构, 能高效处理大量并发连接
* 反向代理: 能将客户端请求转发到后端服务器, 提供负载均衡和缓存功能
* 静态内容服务: 高效地提供静态文件如HTML, CSS, JS和图片
* 可扩展性: 通过模块化设计, 可以根据需求添加或移除功能模块
